# Subtasks

Use this file only when a selected task is too large to complete safely in one turn.

Create subtasks that:

- have one concrete output each;
- can be verified independently;
- preserve the parent task acceptance criteria;
- keep generated images and final source files inside `company/brand/brandbook-packet/`.

Do not use subtasks to hide incomplete work. If a task is blocked, mark it blocked and explain what is needed.
