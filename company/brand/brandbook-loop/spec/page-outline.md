## Magic Mirror page direction

1. Use the Acid combined lockup on Ink for the dark cover.
2. Use the Ink wordmark on White or Cloud for the light cover.
3. Group the contents as Identity, Color & UI, Applications, and Typography.
4. Demonstrate standalone wordmark, combined lockup, full icon, and 16px simplified favicon usage.
5. Include stretching, rotation, gradients, added effects, changed focus corners, low-contrast placement, unapproved recolors, and undersized full-icon use as incorrect examples.
6. Present Acid, Ink, White, and Cloud as the primary operational set, with Deep and Pale as supporting anchors.
7. Show only documented shades derived from approved anchors; label the method and exact hex values.
8. Show primary, secondary, text-link, hover, focus, and disabled UI states using saved tokens.
9. Build badges, callouts, header blocks, tooltips, and small UI markers from the Editorial Edge direction.
10. Use calculated WCAG data, not visual judgment.
11–17. Reference only the final raster mockups saved under `company/brand/brandbook-packet/mockups/`.
18. Use the selected real display and UI/body fonts from the token task.
19. Show concrete tracking, line-height, contrast, and display-face misuse examples.

## Page design requirements

- Use a clean editorial brandbook layout inspired by references, not copied from them.
- Use the user's brand only.
- Keep page numbers and subtle footer.
- Use local raster mockup assets.
- Keep margins, typography, line rules, card radius, and captions consistent.

## Verification

Source is complete only when every requested page exists, every image reference resolves locally, copied reference-brand names are absent, and UI colors match approved tokens.
