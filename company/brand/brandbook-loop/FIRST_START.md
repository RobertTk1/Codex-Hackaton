# First Start

Use this file only if `tasks.json` is missing.

1. Confirm the brand inputs exist:
   - logo/wordmark source;
   - icon/mark source;
   - palette source;
   - output packet directory.
2. Create `tasks.json` from the default task schema.
3. Create `company/brand/brandbook-packet/` with subfolders:
   - `assets/`
   - `mockups/`
   - `source/`
   - `pages/`
   - `tokens/`
   - `references/`
4. Add a first `progress.txt` entry.
5. Stop after initialization so the next turn starts with a clean task selection.
