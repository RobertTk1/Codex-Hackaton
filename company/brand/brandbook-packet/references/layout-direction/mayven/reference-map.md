# Mayven layout authority for Magic Mirror

The files in this directory are composition references only. They control page geometry, hierarchy, whitespace, density, and standardized application context. They do not authorize copying Mayven's name, copy, Captain Blue palette, travel/cruise imagery, logos, or claims.

- Inspect `pages/contact-sheet.png` before source work.
- Inspect `pages/page-01.png` through `pages/page-19.png` beside the corresponding Magic Mirror page.
- Use `assets/13-favicon.png`, `assets/14-twitter-x.png`, and `assets/15-linkedin.png` as ImageGen composition references for those standardized applications. Twitter/X must pair one light-mode profile/avatar treatment with one dark-mode treatment, reversing the icon for contrast.
- Default canvas is US Letter landscape (`11in × 8.5in`; reference raster `2112 × 1632`).
- Pages 11–17 use a compact title block above one dominant raster mockup.
- Twitter/X and LinkedIn are not interchangeable. X uses a profile hierarchy with distinct light/dark icon treatments; LinkedIn uses a company/profile or experience hierarchy recognizable from layout alone.
- The browser/favicon asset remains separate light and dark raster images with realistic browser chrome.

The global installed skill contains the full reusable mapping at `references/mayven-layout/reference-map.md`.
