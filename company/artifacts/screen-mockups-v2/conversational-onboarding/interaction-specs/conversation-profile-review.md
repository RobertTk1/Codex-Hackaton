# Chat Onboarding — Final Confirmation Interaction Specification

Screen ID: `a97cdab0-56b4-4922-8244-a9b95c1d7381`

The assistant summarizes only customer-provided facts in two short messages and asks one final question. `Change an answer` asks which detail to revisit or lets the customer select the matching transcript message. `Create my style report` validates required inputs, sends one optimistic customer confirmation, disables duplicate submission, and hands off to the existing processing screen. No inferred findings appear before processing.
