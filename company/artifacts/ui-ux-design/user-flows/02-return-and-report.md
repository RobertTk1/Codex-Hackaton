# Flow 02 — Return, Explore, and Recalibrate

Related scenarios: SC-002, SC-009, SC-014

1. A returning customer uses Google or an email magic link.
2. Completed customers land on Style Home; incomplete customers see one specific resume action.
3. Style Home summarizes the report, selected recommendations, live-styling entry, and bag state.
4. The customer opens the report and moves among Overview, Colors, Body style, and Recommendations without losing place.
5. Each recommendation explains the report evidence behind it and can be saved, opened, or sent to live styling.
6. If a color or body-style conclusion feels wrong, the customer can give feedback and start recalibration while the existing report remains available.

Completion signal: the customer finds a useful next action within one screen of login and can trace recommendations back to personal evidence.
